# Подготовка к КР1

## Когда я выберу rebase, а когда merge?
Rebase использую для своей неопубликованной ветки, чтобы обновить основу и очистить историю. Merge использую для объединения общих веток с сохранением истории.

## Что произойдёт после rebase публичной ветки?
Хеши коммитов изменятся. У коллег останется прежняя история, появится расхождение веток. Поэтому общую опубликованную ветку не переписывают без согласования.

## Зачем нужен multi-remote?
Для синхронизации основного репозитория и зеркала, резервирования и работы с исходным репозиторием через upstream. Два push-адреса origin позволяют отправлять один коммит в два места.
